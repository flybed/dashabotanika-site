# «✨ Подобрать другое фото» в черновиках статей

Кнопка в черновике (кабинет → «Статьи» → «Читать и править») подбирает свободные фото по теме статьи.
Нажатие на фото — сайт скачивает его к себе, ставит обложкой и сам пишет в конце статьи строку
«Фото на обложке: автор, лицензия». Пользоваться могут администраторы и модераторы.

Источники (код — `pocketbase/pb_hooks/photopick.js`):

1. **Pixabay** — первым, если подключён ключ. Современные фото еды, дома, природы. Лицензия Pixabay: можно бесплатно,
   в том числе на коммерческом сайте, подпись не обязательна (мы всё равно подписываем автора). Фото храним у себя — так и требует Pixabay.
2. **Pexels** — если подключён ключ (в ноябре 2026 Pexels временно не выдаёт новые ключи; код готов на будущее).
3. **Wikimedia Commons** — CC0, Public domain, CC BY, CC BY-SA.
4. **Openverse** — то же, в основном фото с Flickr.

Тему по-английски составляет Yandex AI Studio из заголовка (ключ — тот же, что у ИИ-помощника, `docs/ai-helper.md`).
Превью идут через наш сервер (`/api/photopick/thumb`), поэтому открываются и из России.

## Как подключить Pixabay (5 минут, бесплатно)

1. Зарегистрироваться на **https://pixabay.com/accounts/register/** (почта или Google) и подтвердить почту.
2. Войти и открыть **https://pixabay.com/api/docs/** — в разделе «Search Images» → «Parameters» в строке `key`
   уже написан ваш ключ (зелёным, длинная строка из цифр и букв через дефис). Форм заполнять не нужно.
3. Скопировать ключ. **Никому не пересылать, в чат не вставлять.**
4. Открыть **https://dashabotanika.ru/_/** (вход суперпользователя) → коллекция **settings** → строка **`PIXABAY_API_KEY`**
   → в поле `value` вставить ключ → сохранить. Перезапуск не нужен.
5. В окне подбора появятся «Источник: Pixabay…» и ссылка «Фото с Pixabay».

Лимит — 100 запросов в минуту: одно нажатие «Подобрать» тратит 1–3 запроса.

## Как подключить Pexels (когда снова начнут выдавать ключи)

1. Зарегистрироваться на **https://www.pexels.com/join** (почта или Google).
2. Открыть **https://www.pexels.com/api/** → «Your API Key» (или «Get Started»). Заполнить короткую форму:
   - Project name: `DashaBotanika`
   - Project description: `Подбор обложек со свободной лицензией для статей эко-блога`
   - Website: `https://dashabotanika.ru`
   - согласиться с условиями → ключ появится сразу на этой же странице.
3. Скопировать ключ (длинная строка из букв и цифр). **Никому не пересылать, в чат не вставлять.**
4. Открыть **https://dashabotanika.ru/_/** (вход суперпользователя) → коллекция **settings** → строка **`PEXELS_API_KEY`**
   → в поле `value` вставить ключ → сохранить.
5. Всё: перезапуск не нужен. В окне подбора появится «Источник: Pexels…» и ссылка «Фото предоставлены Pexels».

Лимит бесплатного ключа — 200 запросов в час и 20 000 в месяц: одно нажатие «Подобрать» тратит 1–2 запроса.

Проверка для команды сайта: `GET /api/photopick/search?q=frozen%20berries&debug=1` (под входом администратора) —
в ответе `from` начинается с «Pixabay» (или «Pexels»), а в `log` видно, что ответил каждый источник.
