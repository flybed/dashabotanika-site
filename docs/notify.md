# Уведомления: почта и Telegram

Участник сам выбирает в кабинете → «⚙️ Профиль и настройки» → «🔔 Уведомления», что и куда присылать:

| Что | ✉️ Почта | ✈️ Telegram |
|---|---|---|
| 🌱 Напоминание о челлендже (каждый день) | — | да |
| 🏁 Начать новый челлендж (воскресенье) | — | да |
| 💬 Личные сообщения | не чаще раза в 3 часа | сразу |
| 📖 Новые статьи | да | да |
| 📬 Письмо недели (воскресенье, 11:00 МСК) | да | да |

- Почта уходит через почтовые настройки PocketBase (Unisender Go, адрес `hello@dashabotanika.ru`):
  https://dashabotanika.ru/_/#/settings/mail
- Галочка «почта» = согласие на эти письма; время согласия хранится в `notify.consent_at`.
- В каждом письме — «Отписаться» (одна ссылка, без входа) и заголовок `List-Unsubscribe` для почтовых программ.
- Письмо недели: новые статьи за неделю, новые жители и вещи, «ваша неделя» (очки роста, уровень). Если рассказать нечего — не отправляется.
- Код: `pocketbase/pb_hooks/notify.js`, `notify.pb.js`; Telegram — `tg.js`. Проверка: `PB=pocketbase sh tests/notify_test.sh`.
- Разослать письмо недели вручную (суперпользователь): `POST /api/notify/weekly`.
