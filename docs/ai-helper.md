# ИИ-помощник по фото

Раздел «Умный помощник» на главной: участник загружает фото тарелки или упаковки и получает совет —
как сделать блюдо полезнее и экологичнее, или из чего упаковка, куда её сдать и как использовать повторно.

- Модель — Yandex AI Studio с распознаванием изображений (по умолчанию `gemma-3-27b-it`), запросы идут с нашего сервера.
- Только для зарегистрированных, **5 фото в день** на человека (меняется переменной `AI_DAILY`).
- Фото уменьшается в браузере до 1024 px и не сохраняется; в базе (`ai_uses`) — только факт разбора и число токенов.
- Примерно 1–2 ₽ за фото. В Yandex Cloud поставить бюджет с уведомлением (Биллинг → Бюджеты), например 1 000 ₽ в месяц.

## Как подключить (один раз)
1. **console.yandex.cloud** → создать платёжный аккаунт (проверить, начислен ли стартовый грант).
2. Создать **каталог** (или взять `default`) и скопировать его **ID** (вида `b1g…`) — это `YC_FOLDER`.
3. «Сервисные аккаунты» → создать аккаунт (например `dashabotanika-ai`) с ролью **`ai.languageModels.user`**.
4. В этом сервисном аккаунте → «Создать новый ключ» → **API-ключ** (область — `yc.ai.languageModels.execute`, если спросит). Скопировать секрет — это `YC_API_KEY`.
5. Вписать их в админке — без входа на сервер: **https://dashabotanika.ru/_/** → коллекция **settings** →
   в строке `YC_FOLDER` в поле `value` вставить ID каталога, в строке `YC_API_KEY` — секрет ключа, сохранить.
   Помощник включается сразу, перезапуск не нужен. Коллекцию видит только суперпользователь.

   Другой способ — файл на сервере (переменные окружения важнее настроек из админки). На сервере (`ssh root@201.24.61.171`):

```sh
sh -c 'printf "ID каталога: "; read F; printf "API-ключ: "; read K; printf "YC_FOLDER=%s\nYC_API_KEY=%s\n" "$F" "$K" > /etc/dashabotanika/ai.env'
chmod 600 /etc/dashabotanika/ai.env
systemctl restart pocketbase
```

Ключ в чат и в репозиторий не пишем. Сервис PocketBase читает файл при запуске (`EnvironmentFile` в `deploy/pocketbase.service`).

## Проверка без Яндекса
`PB=pocketbase sh tests/ai_test.sh` — подставной API вместо Yandex AI Studio.
