# Индексация в Яндексе и Google

## Что делает сайт сам
- Карта сайта https://dashabotanika.ru/sitemap.xml — все страницы, статьи, справочник, города.
- `robots.txt` открывает сайт (кроме кабинета и служебных адресов) и картинки статей (`/api/files/`).
- Готовые страницы для поисковиков: заголовок, описание, текст, разметка (статьи, FAQ, хлебные крошки).
- **IndexNow** (`pocketbase/pb_hooks/indexnow.js`): новая или изменённая статья, одобренный сервис — сразу в очередь,
  раз в 5 минут очередь уходит в Яндекс и api.indexnow.org (Bing и др.); по понедельникам — вся карта сайта.
  Ключ публичный — файл `site/1dcff34534a8b98ae5711b664244c85f.txt`. Работает только на сервере (`INDEXNOW=on`).
  Отправить всю карту вручную (суперпользователь): `POST /api/indexnow/all`. Проверка: `sh tests/indexnow_test.sh`.

## Что сделать в кабинетах поисковиков
**Яндекс Вебмастер** — https://webmaster.yandex.ru/sites/
- «Индексирование» → «Файлы Sitemap» → добавить `https://dashabotanika.ru/sitemap.xml`.
- «Индексирование» → «Переобход страниц» — до 20–30 адресов в день: главная, /sortirovka, /markirovka, новые статьи.
- «Индексирование» → «Страницы в поиске» — сколько страниц уже в индексе.

**Google Search Console** — https://search.google.com/search-console
- Добавить ресурс типа «Доменный ресурс» → `dashabotanika.ru` → Google даст запись TXT.
- Вставить её в Webnames (тип TXT, субдомен `@`) → «Подтвердить».
- «Файлы Sitemap» → `sitemap.xml`; «Проверка URL» → «Запросить индексирование» для главных страниц.

Быстрая проверка, что уже в индексе: в Яндексе и Google ищите `site:dashabotanika.ru`.
