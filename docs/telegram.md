# Telegram-бот DashaBotanika

Бот присылает участникам то, что они сами выбрали в кабинете → «Настройки» → «Уведомления в Telegram»:

| Уведомление | Когда |
|---|---|
| 🌱 Напоминание о челлендже | каждый день в выбранное время, если что-то ещё не отмечено |
| 🏁 Начать новый челлендж | по воскресеньям, если челленджа сейчас нет |
| 💬 Новые личные сообщения | сразу |
| 📖 Новые статьи в журнале | когда Даша публикует статью |
| 🌍 Что нового в «Счастливом мире» | по воскресеньям |

Время — местное время участника (берётся из браузера при сохранении). Команда `/stop` в боте отключает всё.

## Как подключить токен (один раз, на сервере)
Токен бота выдал @BotFather. В репозиторий и в чат его не пишем — только в файл на сервере:

```sh
sudo mkdir -p /etc/dashabotanika
sudo sh -c 'printf "Вставьте токен бота и нажмите Enter: "; read T; echo "TG_TOKEN=$T" > /etc/dashabotanika/telegram.env'
sudo chmod 600 /etc/dashabotanika/telegram.env
sudo systemctl restart pocketbase
```

Сервис PocketBase читает этот файл при запуске (`EnvironmentFile` в `deploy/pocketbase.service`).
Сообщения боту сервер забирает сам (`getUpdates`) раз в минуту и каждые 3 секунды, пока человек подключает бота
в кабинете, — входящие запросы от Telegram к серверу не нужны (вебхук до нашего сервера не доходил).

## Как устроено
- `pocketbase/pb_hooks/tg.js` — логика, `tg.pb.js` — маршруты и расписание (напоминания в :07 каждого часа).
- Коллекции `tg_links` (одноразовые коды привязки, сутки) и `tg_subs` (кто подключил, что и когда присылать).
- Проверка без настоящего Telegram: `PB=pocketbase sh tests/telegram_test.sh`.
