# Новые функции — бэклог и порядок

Порядок: сначала переезд (этапы 1–2 из README), затем функции. Регистрация с персонажем
и уровни закладываются в схему PocketBase сразу на этапе 2, чтобы участникам не пришлось
регистрироваться дважды.

## Сразу в этапе 2 (схема и регистрация)
- Регистрация: почта + пароль + персонаж (животное/растение) — обязательные поля.
  Стартовый список персонажей: слон, лиса, ёж, сова, кит, пчела, дуб, берёза, подсолнух, папоротник.
  Даша — первый персонаж, Слон.
- Профиль: уровень (Эко малыш → Эко Чайник → Эко Друг → Эко Продвинутый → Эко Эксперт), очки, анкета.

## Фаза B — без ИИ
1. Личный трекер с ростом: росток → кустик → дерево → лес (растёт от отмеченных дней).
2. 5 уровней + онлайн-сертификаты (страница-сертификат с уникальной ссылкой, можно скачать).
3. «Мой эко путь»: анкета (доставки, многоразовые вещи, уровень погружения) → шкала и советы по правилам.
4. Календарь эко-привычек: «добавить в календарь» из любого раздела (день без пакетов и т.п.).
5. «Счастливый мир»: карта участников с их персонажами.
6. Барахолка: подбор вещей по профилю («нет шопера → вот шопер в барахолке») в личном кабинете.
7. Чистота воздуха по странам и городам (внешнее API качества воздуха, кэш на сервере).
8. Конструктор питания, базовый: цель (экология/похудение/польза/здоровье) → готовый рацион из шаблонов,
   выбранная диета в личном кабинете с отметкой дней.

## Фаза C — с ИИ (нужен выбор провайдера и бюджет)
